# oobCREATIVE SEO + Persona FAQ Framework

Status: active working guidance
Updated: 2026-08-22

## Core rule

Search strategy starts with the question a real audience member would plausibly type into Google or an AI search interface.

A target keyword or question must pass both tests:

1. Would one of the current oobCREATIVE personas plausibly search this?
2. Is it a problem or decision they genuinely need resolved?

Service-category language can support search relevance, but it should not automatically become the emotional opening, H1, or visitor-facing first question.

## Emotional-language rule

Recognition before explanation.
Emotion before technology.
Answer before redirecting.

When a search phrase is technically useful but emotionally cold, preserve the search language in the title, supporting copy, H2 structure, metadata, internal links, or FAQ wording while allowing the first visitor-facing line to begin with the human situation.

Example:

Search subject: AI consulting for small business

Possible emotional H1:

> You know some of this work should be easier.

Supporting language can then establish AI consulting, workflow automation, implementation, websites, communication systems, or other descriptive search language naturally.

## Page-level SEO check-in

Before publishing a significant page, record:

- primary persona or buying state
- primary question/search intent
- primary search phrase
- supporting semantic phrases
- emotional recognition language
- H1 purpose
- H2 / FAQ structure
- internal links in
- internal links out
- related service
- related proof
- related next decision

## Internal linking rule

Use descriptive anchor text when it is natural. Avoid generic Learn More or Read More when the link can explain the next question.

Preferred pattern:

question or emotional tension
→ useful answer
→ related capability
→ relevant proof
→ next useful decision

## SEO review checkpoints

SEO is an embedded review discipline, not a final cleanup pass.

1. Architecture review: search intent, page differentiation, cannibalization, question opportunities, internal linking.
2. Page strategy review: persona, search question, keyword cluster, H1/H2 plan, related content.
3. Copy review: verify natural use of search language in titles, headings, opening copy, anchor text, and support copy.
4. UX/design review: confirm meaningful SEO text remains visible, semantic, readable, and not sacrificed for visual polish.
5. Internal-link review: confirm Answers, Services, Work, homepage, and tools form a useful semantic network.
6. Technical review: titles, descriptions, heading hierarchy, crawlability, canonical behavior, structured data when justified, sitemap, robots, accessibility, and performance.

When an SEO recommendation is deliberately not followed, document why. Brand and emotional-language rules do not automatically override SEO, and SEO does not automatically override the human experience. Resolve the tension deliberately.

## Brand constraints

- Go Deeper, Not Louder.
- Human-centered and practical.
- No hype, fear, condescension, or artificial urgency.
- Avoid robots, glowing AI imagery, and generic futuristic visuals.
- Ballpoint ink blue is the primary interaction accent.
- Warm vermilion may be used sparingly for emotional emphasis, not as a competing UI system.
- Use oobCREATIVE's hand-drawn structural language with restraint.
- Control without complication is a core benefit.
- Do not make ownership or system maintenance the promised reward.
