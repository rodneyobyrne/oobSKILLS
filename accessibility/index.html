Accessibility

The site should be usable without requiring one particular way of seeing, navigating or interacting.

Accessibility is part of how oobCREATIVE evaluates whether a page or tool is ready to use. It is an ongoing practice, not a certification badge.

Need help with a barrier?

Email hello@oobcreative.com with the page, what you were trying to do and what got in the way.

Accessibility is part of normal site quality.

The site is built with semantic page structure, keyboard interaction, visible focus behavior, text alternatives for meaningful images, responsive layouts and readable content hierarchy as part of the same release process used to check links, forms and browser behavior.

Interactive tools are intended to work without requiring a mouse, and important information should not depend only on color, animation or a visual effect.

Automated checks help, but they are not the whole test.

Code and browser checks can catch missing labels, broken landmarks, missing image alternatives and other structural problems. They cannot determine whether every experience is equally understandable or comfortable for every person, device or assistive technology.

That is why a reported barrier is treated as useful product feedback rather than as an exception to the work.

If something gets in the way, describe the task.

Email hello@oobcreative.com. Include the page or tool, what you were trying to accomplish, the browser or device if relevant and what happened instead. You do not need to diagnose the technical cause.

If the site cannot provide the information or function in a usable form immediately, oobCREATIVE will work with you on a practical alternative while the underlying issue is reviewed.

Third-party services have their own accessibility responsibilities.

Some links or service steps may open a third-party platform. oobCREATIVE can choose integrations carefully and avoid unnecessary barriers, but it does not control the accessibility of independent third-party products. If a third-party step blocks access to an oobCREATIVE service, report it so another path can be considered.

This page describes a commitment, not a compliance certification.

oobCREATIVE does not use this page to claim that every page, tool, browser combination or third-party integration is perfectly accessible. The commitment is to design access into the work, test what can be tested, respond when something fails and improve the system when a barrier is found.

Go deeper, not louder.
